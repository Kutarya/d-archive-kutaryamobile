# Kutarya Mobile

- Önce DEVIR.md ve docs/PLAN.md okunur; her görevin sonunda DEVIR.md güncellenir.
- Uygulama Kutarya Mobile, asistanın görünen adı Kutarya Us.
- Kullanıcı Türkçe konuşur; arayüz ve açıklamalar Türkçedir.
- Kaynak, derleme, araç kopyaları, önbellek ve çıktılar D:/KutaryaMobile altında.
- İzin ve işlem doğrulama kapısını model kararıyla kaldırma. Gerçek sonuç olmadan başarı bildirme.
- API anahtarı, rehber, bildirim, sohbet veya kullanıcı dosyası loga/APK/kaynak paketine girmez.
- Canlı Firebase/Hosting/ortak Auth ve başka Kutarya uygulamalarının değişikliği bu kapsamda değildir.
- Testte kontrollü API yanıtı ile gerçek model/telefon kabulünü ayrı raporla.
- PowerShell betikleri UTF-8 BOM ister. Geri dönüşsüz işlemde hedef yolu kontrol et.
